# arqs-arcade-labs
ARQS Arcade Labs - Paddle, Break, and Drop interactive browser games. Pure HTML5 Canvas + vanilla JS. Part of ARQS Software Intelligence Systems.

## Games
- **Paddle Lab**: Classic paddle/ball. Mouse, keyboard (arrows/WASD), touch controls. Pause with P or Space. Best score saved locally.
- Break Lab, Drop Lab: see respective HTML files.

Open any .html file in a browser. No build step required.
