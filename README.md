# arqs-arcade-labs
ARQS Arcade Labs - Paddle, Break, and Drop interactive browser games. Pure HTML5 Canvas + vanilla JS. Part of ARQS Software Intelligence Systems.

## Games
- **Paddle Lab**: Classic paddle ball with mouse/keyboard controls and spacebar pause. Score and local best.
- **Break Lab**: Brick breaker variant.
- **Drop Lab**: Dropping mechanics game.

Open the HTML files directly in a browser. No build step required.
