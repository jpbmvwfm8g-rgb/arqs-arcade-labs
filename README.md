# arqs-arcade-labs
ARQS Arcade Labs - Paddle, Break, and Drop interactive browser games. Pure HTML5 Canvas + vanilla JS. Part of ARQS Software Intelligence Systems.

## Labs
- **Paddle Lab**: Classic defense with progressive speed, lives, pause (P), touch support, local high scores.
- **Break Lab**: Colored blocks, lives, scoring, persistence.
- **Drop Lab**: Falling shapes / line clears (Tetris-style).
- **Risk Pulse** & **Cost Estimator**: Supporting interactive tools.

All labs use pure HTML5 + vanilla JS. LocalStorage where applicable. Ready for ARQS integration events.

## Recent polish (2026-10-15)
Paddle Lab improved with lives system, pause, speed clamping, mobile/touch support, and clearer UX. See branch `improve/paddle-polish-20261015`.
