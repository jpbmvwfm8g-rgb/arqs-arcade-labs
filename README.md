# arqs-arcade-labs

ARQS Arcade Labs - Paddle, Break, and Drop interactive browser games. Pure HTML5 Canvas + vanilla JS. Part of ARQS Software Intelligence Systems.

## Games
- **Paddle Lab** (`paddle-lab.html`): Classic paddle/ball with mouse or keyboard controls. Local high score via localStorage.
- **Break Lab** (`break-lab.html`): Brick breaker variant.
- **Drop Lab** (`drop-lab.html`): Falling objects catcher.

## Controls
- Mouse: Move paddle
- Keyboard: Arrow keys / A D / W S
- Space: Pause (on improved branches)

## Features
- Pure client-side, no backend required
- localStorage for best scores where implemented
- Mobile-friendly canvas

## Next improvements
- Consistent pause across all labs
- Sound effects (optional)
- Difficulty levels
- Export scores
